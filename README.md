# 📝 Task Manager

Современный полноценный менеджер задач с backend, frontend и базой данных SQLite.

![Task Manager Screenshot](./screenshot.png)
*Замените этот файл screenshot.png на реальный скриншот приложения*

## 🚀 Возможности

- ✅ **Полный CRUD функционал** - создание, чтение, обновление и удаление задач
- 🔍 **Поиск задач** - быстрый поиск по названию
- 🎯 **Фильтры** - все задачи, активные и выполненные
- ✏️ **Редактирование** - изменение задач через удобное модальное окно
- ☑️ **Отметка выполнения** - отмечайте задачи как выполненные
- 📊 **Статистика** - отображение количества всех, выполненных и оставшихся задач
- 💾 **Постоянное хранение** - данные сохраняются в базе данных SQLite
- 📱 **Адаптивный дизайн** - работает на компьютерах, планшетах и телефонах
- 🎨 **Современный UI** - минималистичный и приятный интерфейс
- ⚡ **REST API** - полноценное серверное API для работы с задачами
- ✔️ **Валидация данных** - проверка входных данных на клиенте и сервере

## 🛠️ Технологии

### Frontend
- HTML5
- CSS3 (с CSS-переменными и адаптивной вёрсткой)
- Vanilla JavaScript (ES6+)

### Backend
- Node.js
- Express.js
- SQLite3
- CORS

## 📋 Требования

- Node.js версии 14 или выше
- npm или yarn

## 🔧 Установка и запуск

### 1. Клонирование репозитория

\`\`\`bash
git clone <URL_вашего_репозитория>
cd to-do-list
\`\`\`

### 2. Установка зависимостей

\`\`\`bash
npm install
\`\`\`

### 3. Инициализация базы данных

\`\`\`bash
npm run init-db
\`\`\`

Эта команда создаст базу данных SQLite с необходимой структурой таблиц.

### 4. Запуск сервера

\`\`\`bash
npm start
\`\`\`

Или для разработки:

\`\`\`bash
npm run dev
\`\`\`

### 5. Открыть приложение

Откройте браузер и перейдите по адресу:

\`\`\`
http://localhost:3000
\`\`\`

## 🔌 API Endpoints

### Получить все задачи
\`\`\`
GET /api/tasks
\`\`\`

### Получить задачу по ID
\`\`\`
GET /api/tasks/:id
\`\`\`

### Создать новую задачу
\`\`\`
POST /api/tasks
Content-Type: application/json

{
  "title": "Название задачи"
}
\`\`\`

### Обновить задачу
\`\`\`
PUT /api/tasks/:id
Content-Type: application/json

{
  "title": "Новое название",
  "completed": 0 или 1
}
\`\`\`

### Переключить статус задачи
\`\`\`
PATCH /api/tasks/:id/toggle
\`\`\`

### Удалить задачу
\`\`\`
DELETE /api/tasks/:id
\`\`\`

## 🎯 Использование

1. **Добавление задачи**: Введите название задачи в поле ввода и нажмите "Добавить" или Enter
2. **Отметка выполнения**: Нажмите на чекбокс рядом с задачей
3. **Редактирование**: Нажмите кнопку "Изменить", измените текст и сохраните
4. **Удаление**: Нажмите кнопку "Удалить" и подтвердите действие
5. **Поиск**: Введите текст в поле поиска для фильтрации задач
6. **Фильтры**: Используйте кнопки "Все", "Активные" и "Выполненные" для фильтрации

## ⚙️ Конфигурация

Вы можете настроить порт сервера, создав файл \`.env\` на основе \`.env.example\`:

\`\`\`bash
cp .env.example .env
\`\`\`

Затем отредактируйте \`.env\`:

\`\`\`
PORT=3000
\`\`\`
