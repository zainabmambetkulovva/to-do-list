# 🚀 Быстрый старт Task Manager

## Установка и запуск за 3 шага

### 1️⃣ Установите зависимости
```bash
npm install
```

### 2️⃣ Инициализируйте базу данных
```bash
npm run init-db
```

### 3️⃣ Запустите сервер
```bash
npm start
```

### ✅ Откройте в браузере
```
http://localhost:3000
```

---

## 🔧 Решение проблем

### Порт 3000 занят?

**Windows:**
```bash
# Найти процесс
netstat -ano | findstr :3000

# Остановить процесс (замените PID на номер из предыдущей команды)
taskkill /F /PID <номер_процесса>
```

**Или измените порт:**

Создайте файл `.env` и укажите другой порт:
```
PORT=3001
```

### База данных не работает?

Удалите файл базы и создайте заново:
```bash
rm backend/database/tasks.db
npm run init-db
```

### Проблемы с зависимостями?

Удалите node_modules и переустановите:
```bash
rm -rf node_modules package-lock.json
npm install
```
